# Intensivão de Programação

Repositório criado para desenvolver e consolidar minha habilidade prática
de programação, com foco inicial em Java e posteriormente em Spring Boot.

O objetivo principal é aprofundar meu conhecimento teórico em capacidade de
implementar soluções de forma independente.

## Objetivos

- Desenvolver autonomia para programar sem depender de código gerado por IA
- Melhorar resolução de problemas
- Praticar orientação a objetos
- Melhorar debugging
- Trabalhar com coleções e estruturas de dados
- Implementar regras de negócio
- Praticar Git e GitHub
- Desenvolver projetos completos
- Evoluir posteriormente para Java + Spring Boot
